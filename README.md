# 🌱 儿童成长助手

儿童全周期学习成长计划：目标管理、每日监控、周期复盘、成长档案、时间统计于一体的成长记录工具。

## 在线地址

https://wyting1234.github.io/child-growth-assistant/

## 🧭 导航结构

全站导航统一收进 **左侧垂直居中的汉堡按钮**（`site-nav.js`，所有页面共用一份组件）。点开抽屉后只有三类内容：

1. `🧭 返回导航中心` —— 唯一的跨页出口，任何子页面都能一键回到 `index.html`
2. `本页快捷` —— 当前页面内部的区块 / 标签跳转，不跨页
3. `☁️ 云备份` / `👤 学员管理` / `🌗 页面变色` —— 三个常用功能

子页面不再平铺其它页面链接，也不再各自维护侧边栏。新增页面只需引入 `site-nav.js`，用 `data-title` 声明页面名、`data-sections` 声明页内快捷即可。

## 功能模块

- ⏱️ 总览：时间统计（日/周/月/年）、计时器、今日时段环形图、待办清单
- 🎯 目标库：年度 / 月度 / 每日三级目标体系
- ✅ 每日监控：固定任务 + 临时事项打卡，自动生成成长计划完成表（可打印 / 导出图片）
- 📝 周期复盘：周复盘、月复盘模板
- 📂 成长档案：成长里程碑、数据导出备份
- 📋 指标库：目标 → 行动 → 要点三级分类，可复用的打卡任务模板

## ☁️ 云端同步

数据默认保存在浏览器 localStorage。点击右上角「☁️ 云同步」配置 GitHub Token 后，可将数据上传到私有 Gist 云端备份，实现多设备恢复：

1. 点击「☁️ 云同步」→「重新配置 Token」→ 按提示生成 GitHub Token（勾选 gist 权限）并粘贴
2. 在「源头」设备点「⬆️ 上传到云端」
3. 在其他设备点「⬇️ 从云端下载」

每次上传 / 下载前都有覆盖确认，避免误操作。
